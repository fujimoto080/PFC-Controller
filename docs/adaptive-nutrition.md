# カロリー超過の緩やかな自動調整

## 研究・指針と設計の区別

[NICE NG246（2026年更新）](https://www.nice.org.uk/guidance/ng246/chapter/Physical-activity-and-diet)は、体重管理で摂取エネルギーを消費より低く保ち、個人に合った栄養バランスの取れた方法を採ることを推奨する。特定の炭水化物・脂質の超過を翌日に同量差し引くルールは示していない。

[BMJ 2025の99試験のネットワークメタ解析](https://www.bmj.com/content/389/bmj-2024-082007)では、断続的制限と継続的制限の効果は概ね似ており、隔日断食の追加効果も小さい。食べすぎを急な断食で埋め合わせる優位性を裏付ける研究ではない。

本アプリの「7日で分散・1日5%かつ100kcalまで・総赤字25%まで」は、研究で最適値が確立した処方ではなく、急激な食事制限を避けるための保守的な実装方針。既存の最低カロリー（男性1500、女性1200）はアプリの一般的な下限であり、個人ごとの安全性を保証する値ではない。

## 計算

- 基本目標はプロフィールから求める。運動量は活動レベルに含める。
- 記録済み過去日の「実際の摂取 − 基本目標」が正なら、超過として保存せず履歴から計算する。
- 後日、実際に基本目標以下で食べた分を古い超過から相殺する。目標を減らしただけでは相殺しない。
- 不足を先取りした食事枠は作らない。未記録日、既定の最低カロリー未満の記録は相殺に使わない。
- 各超過は翌日から7日間だけ扱い、残額を残りの日数で分けた額を今日の減額候補にする。
- 減額は基本目標の5%、100kcal、下限までの余裕のうち最小。下限は既定の最低カロリー、維持カロリーの75%、固定したP/Fのエネルギーの最大。
- PとFは基本目標のまま、Cを `(今日のカロリー − 4P − 9F) / 4` で再計算する。
- 7日間で調整できない分は、無期限の負債にしない。目標は無理な返済を要求しない。
- 栄養素別の超過・不足は持ち越さない。Cが目安を超えても総カロリー内なら減額しない。

## 記録の限界

食事記録だけでは、記録漏れと実際の不足を完全には区別できない。最低カロリー以上でも記録漏れは起きるため、毎日の食事を漏れなく記録する必要がある。週平均は記録日だけの平均であり、実際の摂取量を保証しない。プロフィールや体重が変わった場合は現在の基本目標で再評価する。体重の傾向から維持カロリーを学習する機能は含まない。

## 比較したダイエット理論と採用判断

| 理論・手法                 | 研究から読み取れる範囲                                                                                                                                                                                                | アプリへの採用判断                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| カロリー収支               | NICEは継続するエネルギー赤字と個人への適合を推奨                                                                                                                                                                      | 基本目標と短期調整の中心に採用。超過の全量返済は要求しない                                              |
| 糖質制限と脂質制限         | [DIETFITS](https://jamanetwork.com/journals/jama/fullarticle/2673150)の609人・12か月試験では健康的な低糖質食と低脂質食の減量差は有意でない。特定集団の結果であり全食事法が同等という意味ではない                      | 栄養素別の超過を翌日へ返済させない。Pを確保しF/Cは柔軟な目安とする                                      |
| 断続的断食                 | [BMJ 2025](https://www.bmj.com/content/389/bmj-2024-082007)では継続的制限との差は概ね小さい                                                                                                                           | 自動の絶食日・罰としての断食を設けない                                                                  |
| 食事時間・概日リズム       | [BMJ Medicine 2026](https://bmjmedicine.bmj.com/content/5/1/e001071)では早い時間帯の時間制限食に利点を示す。ただし窓の長さの結果は一貫せず、すべての条件で同じ効果とはいえない                                        | 時間帯だけでカロリーを罰則的に減らさない。生活予定に合う食事時刻を提案する                              |
| 高たんぱく質               | [2024年のメタ解析](https://pubmed.ncbi.nlm.nih.gov/39002131/)は減量中の筋量維持への利点を示す。個別に1.6g/kgが最適と保証する研究ではない                                                                              | 毎日のP目標を守り、超過調整で減らさない                                                                 |
| 筋力トレーニング           | [2025年のメタ解析](https://doi.org/10.1136/bmjsem-2024-002363)では食事制限に抵抗運動を加えると体重の差は小さいが、筋量・筋力などに利点がある                                                                          | 体重だけを健康効果の指標にせず、運動の消費を食事枠に全量足さない                                        |
| ダイエット休止・リフィード | [2025年のメタ解析](https://pubmed.ncbi.nlm.nih.gov/38193357/)は体組成への明確な優位性は示さず、代謝への効果は研究条件に依存する                                                                                       | 無制限のチートデーや代謝のリセットを保証しない                                                          |
| 食品の質・満腹感           | [NIHの2019年の入院クロスオーバー試験](https://pubmed.ncbi.nlm.nih.gov/31105044/)では20人の参加者が超加工食条件で多く食べた。加工食品すべてが同じ影響という結論ではない                                                | 献立では野菜、食物繊維、たんぱく源と満腹感を考慮。便利な食品を一律禁止しない                            |
| 動的な代謝・水分           | [NIH Body Weight Planner](https://www.niddk.nih.gov/research-funding/at-niddk/labs-branches/laboratory-biological-modeling/integrative-physiology-section/research/body-weight-planner)は体重・代謝・活動の変化を扱う | 7200kcal/kgは粗い初期目安として扱い、目標期間を厳密な予測と表示しない。単日の体重増を脂肪増とみなさない |
| 記録とフィードバック       | [2024年のメタ解析](https://pubmed.ncbi.nlm.nih.gov/38178230/)では記録へのフィードバックを検討しているが、特定の自動調整式の有効性は確立しない                                                                         | 基本目標・今日の調整・記録日数を表示する。記録漏れを真の不足と断定しない                                |

現在の自動調整は食事履歴に基づく短期の緩やかな補正。長期の維持カロリーの推定には、十分な体重・食事・活動データと、水分変動をならした傾向が必要。現時点でNIHの動的モデルを実装したとは扱わない。将来の体重推移による補正は、単日の値ではなく複数週の記録で別途検証する。
